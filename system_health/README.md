# 🖥️ System Health Monitor (Python)

A lightweight Python automation script to monitor system health metrics such as **CPU usage, RAM usage, disk usage, and battery status**, and log them for later analysis.

---

## 📌 Features
- 🧠 CPU usage monitoring  
- 💾 RAM usage tracking  
- 📂 Disk usage check  
- 🔋 Battery percentage detection (if supported)  
- 📝 Timestamped logging  
- ⚡ Lightweight and cross-platform  

---

## 🛠️ Tech Stack
- Python 3.x  
- `psutil` library
