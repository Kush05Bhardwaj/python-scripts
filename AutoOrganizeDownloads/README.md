# 📂 Downloads Folder Organizer (Python)

A simple and effective **Python automation script** that automatically organizes files in your **Downloads** folder into categorized subfolders like Images, Videos, Documents, Music, and Archives.

---

## 🚀 Features

- Automatically scans your `~/Downloads` directory  
- Sorts files based on file extensions  
- Creates folders if they don’t already exist  
- Moves files into appropriate folders  
- Lightweight, fast, and beginner-friendly  

---

## 🧠 How It Works

The script:
1. Reads all files from your **Downloads** folder  
2. Checks each file’s extension  
3. Matches it to a predefined category  
4. Moves the file into the corresponding folder  

---

## 📁 File Categories

| Folder | Extensions |
|------|-----------|
| Images | `.jpg`, `.jpeg`, `.png`, `.gif` |
| Videos | `.mp4`, `.mkv` |
| Docs | `.pdf`, `.docx`, `.txt` |
| Music | `.mp3`, `.wav` |
| Zips | `.zip`, `.rar` |

---

## 🛠 Requirements

- Python **3.x**
- No external libraries required
