# 🌙 Evernight — Animated Desktop Widget (Python)

A sleek, minimal desktop widget built with **Python + Tkinter**, featuring a frameless transparent GIF avatar that stays on top of your workspace.  
Designed for devs who love aesthetic and functional desktop companions ✨

---

## 🧩 Features

- 🖼️ Animated transparent GIF avatar  
- 🪟 Borderless, draggable floating window  
- 📍 Always-on-top behavior  
- 🧊 Custom app icon  
- ⚙️ Buildable into a standalone `.exe` (no console)
